# Minimal To‑Do

Минималистичное локальное приложение для ведения списка задач. Оно работает целиком в браузере: не требует регистрации, сервера или подключения к внешним API. Все задачи и выбранная тема сохраняются в `localStorage` конкретного браузера.

## Возможности

- создание задачи с категорией: «Работа», «Личное» или «Учёба»;
- выбор приоритета: высокий, средний или низкий;
- отметка задачи как выполненной и автоматический расчёт прогресса;
- редактирование текста двойным кликом;
- удаление задачи с возможностью отмены в течение 4 секунд;
- поиск и фильтрация по статусу и категории;
- светлая и тёмная темы;
- адаптивный интерфейс для мобильных устройств и десктопа;
- защита от пустых задач с визуальной подсказкой;
- корректный перенос длинного текста в карточках;
- экспорт задач в JSON и импорт валидной JSON‑резервной копии;
- информативное пустое состояние для нового списка.

## Технологии

| Инструмент | Назначение |
| --- | --- |
| React 19 | Компоненты и состояние интерфейса |
| TypeScript | Типизация данных и props компонентов |
| Vite | Локальная разработка и production-сборка |
| Tailwind CSS 4 | Адаптивные стили и тёмная тема |

## Быстрый старт

### Требования

- Node.js 20 или новее;
- npm 10 или новее.

### Установка и запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`. Откройте его в браузере.

### Проверка качества

```bash
# Автоматические тесты
npm test

# Проверка TypeScript и production-сборка
npm run build
```

## Резервные копии

Кнопка **«Экспорт в JSON»** скачивает файл `todo-backup.json` с текущими задачами. Для восстановления выберите этот файл кнопкой **«Импорт из JSON»**.

Импорт проверяет каждый элемент: требуются идентификатор, текст, допустимые категория и приоритет, а также статус выполнения. При ошибке список задач не меняется. Успешный импорт заменяет текущий список задач, поэтому экспортируйте актуальную копию перед восстановлением данных.

## Как велась разработка

Проект создавался совместно с OpenAI Codex в итеративном режиме:

1. Согласовали стек: React, TypeScript, Tailwind CSS и Lucide.
2. До реализации ключевых сценариев добавлялись автоматические тесты: создание, выполнение, редактирование, фильтрация, удаление с отменой, импорт и экспорт.
3. После каждого изменения запускались тесты и production-сборка TypeScript/Vite.
4. Интерфейс проверялся локально в браузере, включая пустое состояние, валидацию и адаптивную вёрстку.
5. Логика была разделена на небольшие React-компоненты с одной ответственностью, а работа с данными вынесена в отдельный модуль LocalStorage.

ChatGPT и OpenAI Codex использовались как помощники по проектированию, написанию тестов, реализации интерфейса, рефакторингу и локальной проверке. Приложение не отправляет пользовательские задачи во внешние сервисы и не публикуется автоматически.

## Ограничения

- данные доступны только в том браузере и профиле, где они созданы;
- нет синхронизации между устройствами;
- импорт заменяет текущий список, а не объединяет его с ним.
